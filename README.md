# Лабораторная работа 10. Текстовые файлы и обработка ошибок

Выполнил: Вариант 1 (Сумма положительных элементов)

## Описание программ

- `files_lab.py` - модуль для чтения и валидации текстового файла с матрицей (`read_matrix`), а также вычисления суммы элементов по варианту (`selected_sum`).
- `table.py` - переиспользуемый модуль из работы №9 для расчета сумм строк и столбцов.
- `main.py` - главная программа с защищенным вводом чисел (`read_positive_integer`), обработкой исключений чтения файла и записью отчета.
- `test_files.py` - модуль автоматического тестирования с использованием временных директорий (`tempfile.TemporaryDirectory`).
- `matrix.txt` - входной текстовый файл с матрицей.
- `report.txt` - итоговый текстовый отчет с результатами расчетов.

## Формат входного файла (matrix.txt)

1. Первая строка содержит два положительных целых числа через пробел - количество строк $R$ и столбцов $C$.
2. Следующие $R$ строк содержат ровно $C$ целых чисел, разделенных пробелами.
3. Кодировка файла - UTF-8.
